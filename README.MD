# AI Generated E-Commerce Website

## Overview

This is a responsive E-Commerce website designed and generated using **Claude AI** and implemented using **HTML and CSS**. The project focuses on building a modern and visually appealing front-end layout for an online shopping platform.

## Features

* Fully responsive design for all screen sizes
* Modern navigation bar
* Hero section with promotional banner
* Product categories (Men, Women, Kids)
* Featured products display section
* Customer reviews section
* Footer with basic information
* Smooth hover effects and UI interactions

## Technologies Used
* Claude AI (for design assistance and layout generation)


## Sections Overview

### Navigation Bar

Provides links to different sections of the website for easy navigation.

### Hero Section

Displays the main banner to attract users and highlight promotions.

### Featured Products

Displays product cards in a clean grid layout.

### Customer Reviews

Shows sample reviews to improve user trust and UI presentation.

### Footer

Contains basic copyright information and links.

## Purpose of Project

This project was created to practice:

* Front-end web development
* UI/UX design principles
* Responsive layout building
* HTML & CSS structuring
